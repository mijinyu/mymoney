# 나만의 가계부 (mymoney)

카드·은행·현금·모임통장을 한 곳에서 관리하고 **돈을 모으는** 것을 목표로 하는 개인 가계부 웹앱입니다.
PC·모바일 브라우저에서 모두 쓸 수 있고, 홈 화면에 설치하면 앱처럼 동작합니다(PWA).

## 주요 기능

- **홈 대시보드** — 전체 자산, 이번 달 수입/지출, 다가오는 카드값, 남은 용돈, 저축 목표를 한눈에
- **자산 관리** (전부 직접 추가·수정·삭제)
  - **카드** — 이번 달 사용액(청구 예정), 실적(혜택) 목표 금액과 달성률, 출금일, 출금 계좌
  - **은행 계좌** — 여러 개 등록, 계좌 간 이체, 카드 출금 자동이체 기록
  - **현금**
  - **모임통장** — 참여자별 기록
- **거래 입력** — 지출·수입·이체 (날짜·금액·카테고리·결제수단·메모)
- **사진으로 자동 입력** — 은행앱 결제알림·영수증 사진을 넣으면 기기 내 OCR(Tesseract.js)로 글자를 읽어 금액·날짜·가맹점·결제수단을 추정해 채워줌 (저장 전 확인·수정). 인식 엔진은 `src/lib/ocr.ts`, 추출 규칙은 `src/lib/parseReceipt.ts`로 분리되어 있어 추후 AI 인식으로 교체 가능
- **용돈** — 월 용돈 예산을 정하고, 쓴 만큼 차감해 남은 금액 확인
- **월별 보기 · 통계** — 달별 조회, 카테고리별 지출 비중
- **저축 목표** — 목표 금액까지 모으기 진행률 추적
- **카테고리 관리** — 지출/수입 분류 직접 편집
- **데이터 백업/복원** — JSON 파일로 내보내기·불러오기

## 데이터 저장 방식

지금은 데이터가 **사용하는 기기(브라우저)에만** 저장됩니다(IndexedDB, 서버·로그인 없음).
다른 기기로 옮기려면 `더보기 → 데이터 백업 → 내보내기`로 파일을 저장한 뒤,
새 기기에서 `불러오기` 하면 됩니다.

> 나중에 여러 기기가 자동으로 같은 데이터를 보는 **클라우드 동기화**를 붙이기 쉽도록,
> 데이터 접근을 `src/db` 계층으로 분리해 두었습니다.

## 개발

```bash
npm install      # 의존성 설치
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## 기술 스택

- React + TypeScript + Vite
- Tailwind CSS
- Dexie (IndexedDB) + dexie-react-hooks — 로컬 데이터 & 반응형 쿼리
- vite-plugin-pwa — 설치형 PWA

## 폴더 구조

```
src/
  db/          데이터 모델(types)과 Dexie 스키마(database)
  lib/         금액/날짜 포맷(format), 잔액·집계 계산(calc)
  components/  공용 UI, 아이콘, 거래·자산 입력 시트, 레이아웃
  pages/       홈 / 내역 / 자산 / 용돈 / 저축목표 / 카테고리 / 더보기
```
